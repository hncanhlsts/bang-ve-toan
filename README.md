# Bảng Vẽ Toán

Bảng vẽ dạy học môn Toán chạy ngay trên trình duyệt: vẽ tự do, chèn công thức (bộ gõ toán trực quan), vẽ đồ thị và miền nghiệm,
bảng biến thiên, bảng xét dấu, thước kẻ, compa, thước đo góc, hình phẳng và hình không gian dựng sẵn (dùng bộ dựng hình của
[ToanViet Studio](https://github.com/hncanhlsts/toanviet-studio)), trải hình khối, khối tròn xoay từ đồ thị, và máy tính khoa học
bố cục fx-580VN X (MENU, SETUP, CALC, SOLVE, số phức, ma trận, vectơ, thống kê, phân phối…).

**Mở ứng dụng:** https://hncanhlsts.github.io/bang-ve-toan/

Phiên bản 1.13.0. Bản cài đặt cho Windows chạy không cần mạng.
