# Bảng Vẽ Toán

Bảng vẽ dạy học môn Toán chạy ngay trên trình duyệt.

**Mở ứng dụng:** https://hncanhlsts.github.io/bang-ve-toan/
**Bản cài Windows (chạy không cần mạng, tự cập nhật):** https://github.com/hncanhlsts/bang-ve-toan/releases/latest

## Tính năng chính
- Viết, vẽ, hình, chữ; bút cảm ứng nhận lực nhấn; nhiều trang giấy (ô li, chấm, dòng kẻ)
- Công thức bằng bộ gõ toán trực quan; đồ thị, miền nghiệm, bảng biến thiên, bảng xét dấu
- Đồ thị có tham số và thanh trượt; điểm đặc biệt (giao trục, cực trị, giao điểm)
- Thước thẳng, thước đo góc, compa; dựng hình động (điểm, đường, đường tròn, giao điểm…)
- Hình phẳng, hình không gian dựng sẵn (bộ dựng hình của [ToanViet Studio](https://github.com/hncanhlsts/toanviet-studio)): trải hình, khối tròn xoay,
  thiết diện qua điểm tuỳ chọn, tách thiết diện ra hình riêng, giao tuyến của hai mặt phẳng
- Máy tính khoa học bố cục fx-580VN X (MENU, SETUP, CALC, SOLVE, số phức, ma trận, vectơ, thống kê, phân phối…)
- Trình chiếu: bút laser, đèn rọi, che màn, đồng hồ; ghi hình bài giảng; mở PDF làm trang nền; xuất PDF, PNG

Phiên bản 2.3.0.
